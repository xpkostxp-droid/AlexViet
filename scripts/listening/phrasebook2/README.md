# Разговорник 2

59 записей из пользовательского курса: 12 уроков произношения и 47 диалогов, всего 539 заданий. Полные переводы и вьетнамские тексты сохранены из исходного учебника; слова перед прослушиванием извлечены из словарей с сопоставлением целых выражений.

`source-manifest.json` — канонические фразы, словарь и границы исходного звука. Для 1–32 сохранена разметка из восстановленной рабочей ветки. Для 33–59 границы восстановлены по локальному распознаванию речи с сопоставлением исходного текста; числа нормализованы, сложные участки проверены отдельно. Границы могут слегка захватывать паузы между репликами.

Для воспроизведения сборки нужны оригинальные `01.mp3`–`59.mp3` и ffmpeg:

```sh
python3 scripts/prepare-phrasebook2.py --audio-dir /path/to/originals
npm run build
npm test
```

Готовые обработанные MP3 и `src/content/listening/phrasebook2.ts` хранятся в Git. GitHub Pages не требует Python, модели распознавания, исходных MP3 или PDF. Подготовка выполняется один раз; браузер загружает только выбранную запись после начала урока. Между фразами добавлена секунда тишины.

Восстановленная база: `206ab7c360b44fa8b28e62798044de22f88dc02f` из ветки `codex/listening-three-collections`. Прежние идентификаторы «Разговорника 1» и ключ прогресса сохранены.

Текущая публикация: уроки 1–49. Уроки 50–59 сохранены в исходных данных и скрыты до загрузки MP3. После загрузки увеличьте `phrasebook2PublishedLessons` в `src/content/listening/release.ts`.
