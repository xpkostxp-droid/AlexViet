# Вьетнамский язык — сайт для группы

Сайт с теорией и двусторонними русско-вьетнамскими карточками по урокам.
Первая рабочая версия: главный экран, раздел теории (уроки 1–5), карточки для
тренировки, тренировка с самооценкой, гостевой прогресс в браузере.

## Как запустить

Нужен установленный Node.js (18 или новее).

```bash
npm install
npm run dev
```

Дальше откроется адрес вида `http://localhost:5173` — открой его в браузере
(на телефоне работает тоже, если открыть с того же компьютера через адрес в локальной сети).

Собрать финальную версию сайта (папка `dist`):

```bash
npm run build
```

Прогнать проверочные тесты логики тренировки и прогресса:

```bash
npm run test
```

## Публикация на GitHub Pages

Сайт настроен на автоматическую публикацию: `.github/workflows/deploy.yml`
при каждом пуше в ветку `main` сам собирает проект (`npm run build`),
прогоняет тесты и выкладывает `dist` на GitHub Pages — вручную ничего
собирать и загружать не нужно, достаточно запушить изменения (например,
через GitHub Desktop). В `vite.config.ts` для этого стоит `base: './'`
(относительные пути), это позволяет сайту работать что в подпапке вида
`username.github.io/AlexViet/`, что в корне домена — менять не нужно.

## Где находятся учебные материалы

- `src/content/lessons.ts` — список уроков (ID, номер, название).
- `src/content/cards.ts` — карточки, привязанные к урокам по `lessonId`.

Сейчас есть 5 уроков теории (`lesson-1`…`lesson-5`), но карточек для тренировки
к ним ещё нет — `flashCards` пуст. Чтобы добавить новый урок: добавь запись
в `lessons.ts` с новым `id`, и карточки
в `cards.ts` с тем же `lessonId`. ID уроков и карточек должны быть постоянными —
их не стоит менять после публикации, иначе гостевой прогресс участников потеряет связь.

Материалы теории (уроки 1–5: алфавит, согласные и тона, обращения, знакомство,
время глаголов, профессии, места) перенесены из конспекта группы в
`src/content/theory/`. У урока без материалов `sections` в `theoryMaterials`
равен `null` — тогда экран показывает заглушку «Материалы скоро появятся».
Формат блоков теории (таблица, словарь, конструкция, диалог, подсказка,
текст) описан в `src/types.ts` (тип `TheoryBlock`).

## Как устроен прогресс участника

Прогресс тренировок хранится в localStorage браузера устройства (без регистрации).
Ключ — это ID карточки и направление перевода, а не позиция в списке. Формат
данных версионирован (`vietCards.progress.v1`); повреждённые данные не ломают
сайт — вместо них используется пустое хранилище.

## Что уже сделано

- Главный экран с кнопками «Теория» и «Карточки».
- Раздел теории: список уроков + материалы уроков 1–5 (текст, таблицы,
  словари, конструкции фраз, мини-диалоги), адаптированные под телефон.
- Карточки: выбор урока, направления (рус→вьет / вьет→рус), порядка (по порядку /
  вперемешку), переворот, кнопки «Вспомнил» / «Не вспомнил», счётчик, итоги
  тренировки, повтор ошибок.
- Гостевой прогресс сохраняется в браузере и переживает перезагрузку страницы.
- Пустые состояния: урок без карточек, завершённая тренировка.
- Озвучивание вьетнамского слова при тренировке (`src/domain/speech.ts`) — через
  встроенный в браузер синтез речи, без сторонних сервисов. Работает только если
  на устройстве участника уже установлен вьетнамский голос (например, «Линь» на
  macOS) — сайт не может установить голос сам, это ограничение браузера/ОС. Если
  подходящего голоса нет, сайт просто молчит, а не читает слово чужим голосом.

## Что пока не реализовано (сознательно, по плану)

- Управление уроками через облачную базу и защищённая страница администратора —
  сейчас материалы редактируются только через файлы проекта.
- Тест с выбором из четырёх вариантов.
- Интервальное повторение.
- Экспорт/импорт материалов и резервное копирование.
- Аккаунты участников и синхронизация прогресса между устройствами (структура
  данных подготовлена так, чтобы перенос гостевого прогресса был возможен позже).
- Установка сайта значком на главный экран.
- Платный доступ, реклама, аналитика, распознавание речи, ИИ-функции.

## Технические детали

React + TypeScript + Vite, без лишних зависимостей. Код разделён на:

- `src/types.ts` — общие типы.
- `src/content/` — учебные материалы (данные).
- `src/domain/` — логика тренировки и хранения прогресса (чистые функции,
  не зависят от интерфейса).
- `src/components/` — экраны интерфейса.
